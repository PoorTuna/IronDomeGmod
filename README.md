#  Israel's Defense Forces - Iron Dome Air Defense System 

##  Synopsis 
This addon introduces the IDF’s Iron Dome system to Garry’s Mod. Designed to intercept incoming missiles and rockets, it delivers high accuracy and authentic functionality inspired by its real-world counterpart.

##  Features 
- Coordinated Defense – Multiple Iron Dome units share target data for efficient interception.
- Interceptor System – Each unit carries 20 missiles with a 10-second reload cycle.
- Predictive Tracking – Uses advanced interception logic with ~90% accuracy.
- Authentic Alerts – Plays the real Israeli Red Alert siren when threats are detected.
- Custom Model – Includes a detailed Iron Dome prop for added immersion.
- Full Compatibility – Works seamlessly with vanilla and modded missiles, rockets, and bombs.
- Sturdy Build - Can only be destroyed with explosives.
- Two Modes –
- Protective: Ignores the owner’s projectiles.
- Neutral: More aggressive, and may trigger Protective units to engage.

---

##  Usage 
- Placement - Located in the entities Other category.
